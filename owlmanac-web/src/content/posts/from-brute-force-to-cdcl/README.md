# from-brute-force-to-cdcl: how it's made

- **Data:** none; the puzzles are in `engine/puzzles.ts`.
- **WASM:** `sat-lab-wasm`, into `wasm/` (generated): `cd owlmanac-web && npm run wasm -- sat-lab-wasm`.
- **Cover:** drawn by `cover.mjs` from the post's puzzle: `cd owlmanac-web && npm run covers -- from-brute-force-to-cdcl`.
