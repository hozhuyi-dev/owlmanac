# mapping-the-milky-way: how it's made

A notebook post: the page is `owlmanac-notebooks/mapping-the-milky-way/notebook.py`, exported into `notebook/` (generated).

- **Data:** Gaia star densities, JSON, cached in `owlmanac-notebooks/mapping-the-milky-way/data/` by the notebook. Refresh: set `REFRESH = True`, then `cd owlmanac-notebooks && uv run mapping-the-milky-way/notebook.py`.
- **Export:** `cd owlmanac-web && npm run notebooks -- mapping-the-milky-way`.
